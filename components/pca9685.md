# PCA9685: 16-channel PWM / servo driver

| | |
|---|---|
| Interface | I2C, default address `0x40` (A0–A5 pads change it; `0x70` = all-call) |
| Logic VCC | 3.3 V or 5 V; use the MCU's logic voltage (3V3 with an ESP32) |
| Servo power | Separate V+ through the screw terminal |
| PWM | 12-bit, set to 50 Hz for servos |
| Library | [Adafruit PWM Servo Driver](https://github.com/adafruit/Adafruit-PWM-Servo-Driver-Library) |

## Pins (common Adafruit-style board)

Side headers (both sides, same signals): `GND OE SCL SDA VCC V+`. Screw terminal: `V+ GND`.
Servo headers: one row each of signal, V+ and GND per channel.

## Gotchas

- **Feed servo power only through the screw terminal.** Never connect a side-header V+ pin to the MCU.
- **OE** is pulled low on the board (outputs on). Leave it unconnected, or drive it HIGH to disable all outputs.
- The internal oscillator isn't exactly 25 MHz; `pca.setOscillatorFrequency(27000000)` gave correct servo pulses on mine.
- Don't wire a second GND from the side header back to the MCU if ground already arrives through the
  screw terminal path; that makes a loop that can carry servo current through the MCU.
- Chaining two boards: give the second one a different address (bridge A0 → `0x41`).
